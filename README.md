# Nativka

An Android application showcasing native frameworks related to device security and hardware interaction.

## Features

- BiometricPrompt – biometric authentication
- TEE / StrongBox – secure key storage
- NFC – read/write NFC tags
- BLE – scan and connect to BLE devices
- OMAPI – access Secure Element via Open Mobile API

## Tech Stack

- Kotlin
- Coroutines
- Flow
- Hilt
- MVI architecture
- Clean Architecture
- Jetpack Compose
